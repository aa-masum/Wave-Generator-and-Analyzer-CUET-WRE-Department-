# Wave-Generator-and-Analyzer-CUET-WRE-Department-
This project presents a Wave Generation and Analysis System developed for experimental applications in the Water Resources Engineering (WRE) Department at CUET. The system integrates hardware-based wave generation with sensor-driven data acquisition and MATLAB-based signal analysis. <br>

# Overview
The project focuses on generating controlled surface waves and analyzing their characteristics using a non-contact sensing approach. An Arduino-based control system drives the wave generator, while an ultrasonic sensor captures wave motion for further analysis <br>

# Key Features
- Controlled wave generation using a motorized system
- Real-time wave detection using ultrasonic sensing
- Arduino-based data acquisition
- MATLAB-based visualization and signal analysis

# Hardware Components
- Microcontroller: Arduino 
- Wave Generator: DC Motor-based mechanism to produce waves
- Sensor: HC-SR04 Ultrasonic Sensor (for wave detection)
  
# How It Works
- The DC motor-driven mechanism generates waves in the medium (e.g., water tank).
- The HC-SR04 ultrasonic sensor measures distance variations caused by wave motion.
- The Arduino collects sensor data and sends it to a computer.
- MATLAB processes the data to analyze wave properties such as amplitude, frequency, and waveform patterns.
